3. The Left-Shift Moat: Deterministic Python vs. Paid Inference

"Shift the verifiers left — the biggest cost lesson in the fleet." — INCEPT Process Graph (2026-08-26)

In unconstrained agent systems, defective questions fail late in expensive LLM judge loops or autograder re-evaluations. Incept codified the FL-11 compound call-volume insight: autograders and judges compound across forms, spaced returns, mocks, and QC sweeps. By running pure Python structural checks first, millions of paid judge tokens are eliminated before spending a single cent.

Step 1

Deterministic Python Gate

Cost: $0.00

qc_runner.py runs binary structural checks (stems, options, key balance, math verification). Fails instantly on defective syntax with zero network or model calls.
Step 2

Bounded Native QC

Cost: Bounded (~$0.02 - $0.05)

Calls LLM judge only after structural checks pass. Strictly bounded by max_attempts: 1 to 5 with single-attempt pinning.
Step 3

Cold Fleet Gauntlet (Phase 6)

Cost: Final Sweep Only

Runs once over the frozen course tree at ≥95% strict pass bar before dark publish cutover.

6. Forward Investment Guardrails: Guaranteeing Full Return

To ensure that remaining and future AI API spend translates directly into shippable commercial revenue, all active seats operate under four immutable economic guardrails:

  1. Enforce Hard Session Budget Envelopes: Automated agent sessions operate under an explicit budget envelope with a $200.00 minimum baseline per session run (configurable via app.py and INCEPT_BUDGET_CAP_USD). While daily foundry spend across all parallel seats scales to $1,000–$2,000/day during active manufacturing, individual sessions are strictly capped to prevent runaway loops. Unconverged tasks trigger a typed BUDGET_HOLD with structured diagnostics rather than unbounded retries.
  2. Unit of Delivery is the Complete Form: Cease accumulating disconnected queues of individual accepted items. Dispatch and integrate complete coupled exam forms and whole teacher units end-to-end.
  3. Strict One-Round Review Compliance: All agent dispatches must carry the boundary brief and clean sweep receipt, prohibiting multi-round ping-pong.
  4. Drive HumGeo Across the Finish Line (p5 → p8): Commercial return is finalized when bytes are live. HumGeo's final dark publish, cold QC pass, and learner acceptance complete the R&D cycle and unlock live student enrollment revenue.
