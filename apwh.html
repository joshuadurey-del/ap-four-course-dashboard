Definition of done (our side)

All five of these have to be true. None of them is true yet.

  • Every question marked for repair is fixed and saved into the course file of record. Repair here means writing the short explanation of why each wrong answer choice is wrong. 487 of 571 are saved so far. If a question turns out to be unrepairable it moves to the rebuild list instead, so this count can shift. Time left: about 2.5 hours for the last 84. Basis: MEASURED at 33 questions an hour at full tilt (the average of the six busiest hours across 487 timestamped repairs; all 487 succeeded first try, no retries). This leg is off the critical path — it needs only tonight's tagging round, not the shared factory pool.
  • Every question marked for rebuild has been rebuilt by the factory and judged by it. That is 362 questions today. Rebuilding is how a question that is broken in a way repair cannot reach gets replaced. Time: 6–9 hours on a clean run, 10–12 hours allowing for retries. Basis: a dispatch-board projection, not a measurement — 37 batches at the builder's six-worker pace, 9–14 minutes a batch including its safety check. Checked against the runner's own settings: 9.8 questions a batch, inside the agreed cap of ten. No APWH rebuild has actually run yet, so this is the softest number on the page. For contrast, HumGeo measured about 20 minutes per question on its hardest cases; if ours behave like those, this leg doubles. This is the only leg that occupies the shared factory pool.
  • Every question in the final course file carries a skill tag — the label saying which exam skill it tests. 796 of 933 have one saved into the file the checks actually read. The tagging round still running will add more. The tagging tool is not reliable on every question, so any question it cannot settle after repeated tries is sent to be rebuilt rather than given a guessed tag. A wrong tag is worse than no tag. Time: 9.1 hours for the 362 rebuilt questions. Basis: MEASURED at 40 questions an hour, two at a time, from three of today's runs agreeing. Every rebuilt question is brand new and needs its own tag, which is why this leg is easy to forget — it sits in the middle of the chain.
  • The factory has run its one paid quality check across the whole course file, and its verdicts are saved. One pass over all 933, on purpose: fix everything first, then judge once. None of the 933 has been judged yet. Any question the check fails goes back through repair or rebuild and is judged again. Time: 15.5 to 31 hours, about 23 hours in the middle. This is the biggest single leg on the list, larger than the rebuild. Basis: 933 calls at 1–2 minutes each, run one after another. The one-after-another part is not a choice: the tool that runs the check says so in its own documentation, because all the courses share one pool of about eight workers and running checks in parallel starves everyone else. An earlier version of this page said 3.3 hours here, assuming six to eight at once. That was wrong and it was the largest error on the page. The 1–2 minutes per call comes from the HumGeo campaign, and that campaign's own owner has since told us their parallel figure was what their tool was ASKED for, not what the service was measured to give — so treat the per-call cost as sound and anything about parallelism as unverified. Then add the failure loop, which nobody can size yet: at a 10% failure rate about 3 more hours, at 30% about 9.5. That rate is genuinely unknown because none of the 933 has ever been judged. Correction: this page previously said this leg does not occupy the shared pool, citing the plan document. That is misleading and we withdrew it. The check is a direct request that creates no queued job, so the usual pool probe cannot see it — but it still competes for the same eight shared workers, which is exactly why the tool runs its calls one at a time. It therefore DOES contend with other courses, and the receipts the plan claimed this was verified from could not be located.
  • Somebody has clicked through every lesson page against the finished course file, with saved proof. The last such walk was 2026-08-12, before all of this repair work, so it has to be done again at the end. Time: UNMEASURED. 176 lessons. Nobody recorded how long the August walk took, so this is the one line on this list with no number behind it at all.
